---

Você precisa de **Node.js 24** e **Docker**.

<Steps>
<Step>
### baixe o código

```bash
git clone https://github.com/ryansldev/fila-saude.git
cd fila-saude
npm install
```
</Step>
<Step>
### crie os dados de exemplo

```bash
npm run dev:seed
```

Cria o município `exemplo`, com unidades, sessões, equipe e pacientes. Rode de novo para começar do zero.
</Step>
<Step>
### suba tudo

```bash
npm run dev
```

| O quê | Onde |
| --- | --- |
| API | `http://localhost:3333` |
| Painel | `http://exemplo.localhost:3000` |
| Site e docs | `http://localhost:3001` |
</Step>
</Steps>

## mudou uma rota?

Gere a referência de novo:

```bash
npm run docs:openapi
```
