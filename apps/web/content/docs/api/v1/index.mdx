Cada página descreve uma rota: o que ela recebe, o que devolve, os erros possíveis e um exemplo em cURL.
As rotas estão agrupadas por quem as usa:

- **Município**: dados públicos, sem login (municípios, unidades, agenda).
- **Paciente**: o app do paciente, com o login da central.
- **Painel**: a equipe da unidade, com o login do painel.
- **TV**: a TV da unidade, com o token dela.
- **Sistema**: saúde da API e a página do captcha.

Antes de chamar, leia [Municípios](/docs/municipios) (como dizer o município) e
[Autenticação](/docs/autenticacao). Os erros seguem um formato único, explicado em [Erros](/docs/erros).

Esta referência sai do próprio código (`npm run docs:openapi`): se uma rota mudar, ela muda junto.
